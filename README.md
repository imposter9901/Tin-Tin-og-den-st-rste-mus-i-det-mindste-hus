# Tin Tin og den største mus i det mindste hus

Dette er et platformspil, hvor spilleren styrer karakteren Tin-Tin gennem en række platforme for at nå målet, mens han undgår fjenden Allan. Spillet er udviklet i JavaScript ved hjælp af [p5.js](https://p5js.org/).

## 🕹️ Gameplay
- **Mål**: Hjælp Tin-Tin med at nå døren (målet) uden at blive fanget af Allan.
- **Platforme**: Spilleren kan hoppe og bevæge sig mellem platforme.
- **Fjende**: Allan bevæger sig frem og tilbage og skal undgås.
- **Game Over**: Hvis Tin-Tin rammer Allan, slutter spillet.
- **Vind**: Når Tin-Tin når døren, vises en sejrsskærm.

## 🎮 Kontroller
- **Pil højre (→)** eller **D**: Bevæg Tin-Tin til højre.
- **Pil venstre (←)** eller **A**: Bevæg Tin-Tin til venstre.
- **Pil op (↑)**, **W** eller **Mellemrum**: Hop.
